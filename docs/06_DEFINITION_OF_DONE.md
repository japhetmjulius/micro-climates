# Definition of Done

## Data

- [ ] Data sources documented.
- [ ] Licensing/access conditions documented.
- [ ] Raw data preserved.
- [ ] Units standardized.
- [ ] Timestamps standardized.
- [ ] Missing values handled.
- [ ] Outliers investigated.
- [ ] Data quality checks automated.
- [ ] Provenance recorded.

## Geography

- [ ] Study area defined.
- [ ] Coordinate reference systems documented.
- [ ] DEM obtained.
- [ ] Elevation calculated.
- [ ] Slope calculated.
- [ ] Aspect calculated.
- [ ] Land-cover information obtained where available.
- [ ] Spatial data validated visually.

## Analysis

- [ ] Exploratory analysis completed.
- [ ] Seasonal patterns investigated.
- [ ] Spatial patterns investigated.
- [ ] Anomalies investigated.
- [ ] Terrain/environment relationships tested statistically.

## Modelling

- [ ] Baseline model created.
- [ ] Training/test methodology documented.
- [ ] Data leakage checked.
- [ ] ML model evaluated.
- [ ] Baseline comparison completed.
- [ ] Uncertainty/limitations documented.
- [ ] Model version recorded.

## Risk

- [ ] One hazard selected.
- [ ] Indicators documented.
- [ ] Risk methodology documented.
- [ ] Historical events used for validation where possible.
- [ ] Risk output is explainable.
- [ ] System clearly states its limitations.

## Software

- [ ] Code organized.
- [ ] Tests added.
- [ ] Logging implemented where necessary.
- [ ] Environment reproducible.
- [ ] Git history maintained.
- [ ] API documented if created.
- [ ] Dashboard documented if created.

## Research

- [ ] Research questions documented.
- [ ] Methods documented.
- [ ] Experiments logged.
- [ ] Results reproducible.
- [ ] Limitations documented.
- [ ] Conclusions supported by evidence.

## Final principle

A feature is not "complete" because it runs.

It is complete when it is:

```text
implemented
+
tested
+
validated
+
documented
+
reproducible
```
