# Study Area

## Initial Prototype

The first prototype focuses on a region covering part of the Kenyan
highlands.

## Purpose

The region was selected because it contains substantial variation in:

- Elevation
- Slope
- Aspect
- Land cover
- Rainfall
- Temperature
- Vegetation

These characteristics make it suitable for investigating relationships
between terrain and localized climatic conditions.

## Important limitation

The initial bounding box is a prototype research region. The final
